# 澄心問道 App

以一盞茶的時間，整理心中的疑問。

《澄心問道》是一款以手機操作為主的靜態網頁 App，結合：

- 茶老師處世智慧（塔羅建議）
- 易經靜心起卦
- 六次擲幣、逐爻成卦
- 茶老師金句與茶語
- 收藏與分享
- 澄心茶盞延伸內容推薦

## 線上使用

GitHub Pages 發布完成後：

https://jameschien9-debug.github.io/chengxin-wendao-app/

## 主要檔案

- `index.html`：App 畫面、流程與互動功能
- `tea-data.js`：易經卦象與茶思維資料
- `.nojekyll`：讓 GitHub Pages 直接發布靜態檔案

## 操作方式

1. 在首頁輸入心中的疑問。
2. 選擇塔羅建議或易經卦象。
3. 塔羅可選單張指引或三張澄心牌陣。
4. 易經可選靜心起卦或六次擲幣。
5. 結果可收藏於目前裝置，也可分享摘要。
6. 結果頁可前往澄心茶盞觀看延伸內容。

## 資料與隱私

- 問題與收藏使用瀏覽器的 localStorage，保存在目前裝置。
- 本版沒有會員登入，也不會把問題傳送到遠端資料庫。
- 清除瀏覽器資料、更換瀏覽器或更換手機後，收藏不會自動同步。
- 本服務用於整理思緒，不代替醫療、法律、財務或其他專業建議。
